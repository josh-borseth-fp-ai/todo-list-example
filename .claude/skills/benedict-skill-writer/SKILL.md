# Benedict skill writer

Run `benedict guide skills` and follow its format.

- Shared standards go in the organization's skills repository. Guidance for one repository goes in its `.agents/skills/`. Ask if unsure.
- Cover one area. List the defects to report and what not to report. Keep it short.
