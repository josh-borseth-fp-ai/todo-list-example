# Benedict

To review, run `benedict guide` and follow it. To get a PR you wrote or updated reviewed, run `benedict guide handoff` and follow it instead; never review your own PR. If `benedict` is not installed, install it: `npm install -g --allow-remote=all https://github.com/josh-borseth-fp-ai/benedict/releases/latest/download/benedict.tgz`
